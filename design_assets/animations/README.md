# UI animations

Approved WebM source files for frontend-only celebration overlays:

- `Deposit_Success.webm`: plays after a deposit reaches `confirmed`.
- `Hit_Jackpot.webm`: plays before the Jackpot reward artwork appears.
- `Streak_Turned.webm`: plays when the dashboard streak crosses 15 days.

Runtime copies live in `web_app/public/assets/animations/`. These files never determine transaction state, streak eligibility, or wheel outcomes.
