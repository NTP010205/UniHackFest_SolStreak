# SolStreak design assets

This directory is the handoff boundary for source artwork and approved exports:

- `animations/`: approved frontend celebration videos.
- `badges/`: dashboard streak, trophy, coin, and supporting UI artwork.
- `logo/`: product logo, icon, and wordmark variants.
- `wheel/`: wheel prize and segment artwork.

The backend persists only stable badge codes. Frontend code maps those codes to approved artwork; file names or visual assets are not database identity.

All assets are cosmetic and carry no financial value. They are not tokens, NFTs, transferable items, payouts, or redeemable rewards.

Do not commit temporary design files, export caches, editor recovery files, or unnecessarily large binaries. Record approved formats, dimensions, naming, and optimization requirements in the relevant subdirectory README before adding production artwork.
